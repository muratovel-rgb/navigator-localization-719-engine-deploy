# Шаг 9.6. Первичные документы и реальная карточка приёмки

16.10.2026. Функциональность HTML 0.9.2 не менялась.

В разрешённом Drive проведена частичная проверка оригиналов шести PDF: технические условия, два приказа по КД/ТД, два акта испытаний, перечень производственных операций. Значимые страницы осмотрены визуально, контрольные суммы рассчитаны по точным байтам. Просмотр изображения подписи не удостоверяет её подлинность.

Состав из 18 исполнений сопоставлен с таблицей технических условий. Область испытаний сопоставлялась с явным заключением, не с названием общей папки, диаметром или похожим обозначением. Расхождения материала и привода не приравнивались. Неустановленная связь не объявлялась отсутствием документа во всём досье.

В существующую частную карточку добавлены 6 версий документов, 5 вопросов матрицы и 4 проекта дозапросов. Области записей разделены: дозапрос по части исполнений связан со строкой именно этой области. Записан локальный снимок частичной проверки; официальная подача и результат не выдуманы. Сроки и назначения дозапросов обозначены как предложения, сообщения никому не отправлялись.

Карточка прошла валидацию существующей модели, импорт и открытие через собранный HTML, отдельный экспорт и повторный импорт с равенством данных. Клиентские сведения не включены в Git, общий HTML или публичный расчётный запрос. Подробные выводы, источники и дозапросы сохранены отдельно в частном проектном контуре.

Повторный запрос MCP по открытым кодам возвращает общего кандидата без вычислимой ветви. Унаследованный архивный контекст имеет legalVerification=not_verified и не принят как нормативное требование. Реальные стоимости в MCP не передавались, числовой пересчёт не выполнялся.

- Принятая нормативная основа и первичные калькуляции для G11/G12.

Это завершённая частичная проверка конкретных источников, а не полная нормативная/клиентская приёмка или доказательство готовности приложения к промышленной эксплуатации.
