# Step 10.1 — live private dossier and source readers

HTML 0.10.1 and expert Plugin 0.1.11 extend the existing product. The Site retains its identity and sole-owner audience. The shared deterministic engine and normative activation are unchanged.

A create-only, idempotent import preserves the existing source project and refuses a different existing payload. The migration route has a separate temporary runtime secret and accepts no browser Origin. Its actor is explicitly a service import; no visitor identity is impersonated. After migration the secret is removed and the same saved Site version redeployed.

A private pilot with 18 variants and six exact originals was imported into the existing Site. Source bytes were compared to dossier checksums before upload and SHA-256 verified again by the server. The six PDFs contain 109 pages, including six pages processed by Russian/English OCR. Page-level OCR confidence was 79–92. No customer content, credentials or images were included in source, test fixtures or deployment archives.

Live authenticated MCP checks confirmed project listing, exact context, all six stored attachments and seven selected page reads across the originals. A grounded OCR-review proposal was successfully queued as PENDING. The source project stayed revision 1 with its original two remarks; the proposal did not apply itself or alter legal readiness.

Office readers cover DOCX parts, XLSX sheets/cell addresses/cached formula values, and PPTX slide labels. OCR supports sparse-text PDF pages and images; all assets stay on the Site. The user can force OCR on all PDF pages. No macros, formulas or external Office links are executed. DOCX parts and XLSX sheets are not called physical pages.

Checks: 20 reader tests with real OOXML ZIP fixtures and PDF OCR routing, 53 SQLite/HTTP/import checks, all prior web suites, TypeScript and Worker build. A real scan was recognized with the same Tesseract.js package/models. Native browser layout and browser-worker execution remain unverified; model/Node checks do not replace those. First publication archive was found truncated; a smaller LSTM-only archive was verified by gzip/tar before successful publication.

Full normative and client acceptance remains open: official editions, GCV applicability/merged-cell scope, complete evidence by variant, origin chains and cost data. The new text pipeline does not prove signatures, original validity or production operations.
