# Шаг 9.4 — техническая приёмка досье

Дата: 16.10.2026. Предпросмотр HTML 0.9.1. Шаг 9.3 завершён технически: запросы, цепочки объектов, версии пакетов и журнал подачи работают в существующем продукте.

## Изменения

- Пользователь может запросить редактируемую форму. Ответ принимается только после отдельной внутренней проверки редактируемости текущих доказательств по всем исполнениям запроса. Расширение файла не считается доказательством редактируемости.
- Сохраняются имя файла, MIME и вывод проверяющего с основанием. Файл остаётся у пользователя. Новая версия не наследует проверку старой; исправление положительного вывода переоткрывает зависимый принятый запрос. Замороженный пакет сохраняет прежнюю версию и прежний вывод.
- Раскрываемый список показывает текущие документы по исполнениям и отсутствие связей. Наличие хотя бы одного документа не объявляется полнотой требуемого комплекта.
- Закреплённая панель калькулятора скрыта вне расчётного экрана: на мобильной карточке она больше не перекрывает работу с досье.

## Проверка

- `npm test`: исходные числовые, индексные, контекстные и проектные регрессии, 26 workflow-проверок и 12 новых проверок формата.
- `npm run test:web`: 67 проверок собранного HTML, включая 7 новых сценариев формата, импорта и охвата исполнений.
- `npm run test:audit`: 7 Python-тестов таблиц, 6 проверок поиска и контроль проекта поправок. Не активирует новые нормы.
- `browser-acceptance.cjs`: настоящий Chromium 153.0.8010.0; 28 проверок на 1440×1000 и 390×844. Учебный проект с 18 исполнениями: файл и SHA-256 → запрос → отдельные проверки формата и содержания → материал и деталь → пакет → подача одного исполнения → замена документа → неизменность старого пакета → выгрузка и импорт JSON. Ошибок JavaScript, внешних HTTP-запросов и горизонтального переполнения на проверенных экранах нет. Скриншоты поиска, компактной карточки и цепочки осмотрены.

Для повторения нативной проверки нужны Playwright Core и установленный Chromium. Пример: `PLAYWRIGHT_MODULE=/absolute/path/to/playwright-core BROWSER_EXECUTABLE=/absolute/path/to/chromium node browser-acceptance.cjs`. Тест создаёт только синтетические сведения; результаты и снимки идут в игнорируемый `dist/browser-qa`.

## Границы и следующий этап

Прежние JSON 2 и события досье schemaVersion 1 поддерживаются. Новые события могут быть отклонены прежним HTML; нельзя заменять новые данные пустыми или молча отбрасывать поля. Импорт проверяет историю воспроизведением.

Формат проверяет человек. Приложение не открывает офисные файлы и не удостоверяет подлинность. Автоматическая экспертиза №52 и новые расчётные правила не активированы. Основное ядро, веса и пороги остаются прежними.

Следующий этап — фактическая приёмка реального досье и контрольная нормативная сверка: первичные документы по исполнениям, классификация компонентов, достаточность доказательств, спорные даты и официальные тексты. G11/G12 заблокированы до принятого правила и первичных калькуляций. Полная юридическая и клиентская приёмка остаётся открытой. Публикация production требует отдельного решения пользователя.
