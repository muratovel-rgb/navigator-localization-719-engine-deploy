# MCP: общий поиск и детерминированный расчёт

## Источник состояния

В начале расчётного маршрута вызови `engine_health`. Используй фактические версии, а не числа из старых материалов. На 15.10.2026 опубликованы сервис 0.4.1 и движок 0.8.1; это снимок, не требование к будущему ответу.

Различай:

- `rules`: размер каталога подготовленных и нерешённых карточек;
- `indexedPositions`, `indexedSections`: охват поискового индекса;
- `calculationRules`: число реализованных вычислительных ветвей;
- `fullLegalCoverageVerified`: подтверждена ли полнота нормативной базы. `false` нельзя заменить утверждением о полном охвате действующей редакции.

Один продукт использует общий движок. Не создавай второй калькулятор в ответах агента.

## Пять инструментов

1. `engine_health`: наличие ответа, версии и охват. Ошибка/таймаут означает невозможность получить состояние этим вызовом, а не доказанную остановку сервиса. Допустима одна повторная попытка; затем явно обозначь ограничение.
2. `search_localization_rules`: общий индекс плюс подготовленные правила. Для полного списка кандидатов используй `limit` от 1 до 100, `offset` и `nextOffset`. Не называй первую страницу полным результатом. Числовой поиск может вернуть родительский код; проверь назначение, раздел и оговорку «из». Для синонимов выполни отдельные запросы: поиск по характеристикам не гарантирует семантического совпадения.
3. `get_localization_rule`: прочитай каждый кандидат, влияющий на выбор. `rule.criteria[].id` являются идентификаторами входных фактов; не придумывай `criterionId`. Для индексной карточки отдельно вернутся `indexedPosition`, `calculationAvailable`, `requirementContext`.
4. `get_threshold_context`: запрашивай конкретные `ruleId`, `date`, `goal` (`localization`, `registry`, `support`, `procurement`). `null` означает отсутствие числового порога в этом контексте; это не ноль и не доказательство отсутствия других обязательных условий. Проценты для поддержки не подменяют требования для реестра. Не исключай критерии ради удобного результата; основание исключения должно допускаться конкретным правилом.
5. `calculate_localization`: только подготовленная ветвь и подтверждённая применимость. Не подставляй соседнюю насосную/приборную ветвь для отсутствующего изделия. Для `unresolved` и `calculationAvailable=false` расчёт не запрашивай. Верни предварительный разбор нормы и недостающие условия её формализации.

## Архивный контекст

`sourceContextStatus` и `requirementContext.status` обозначают структурное сопоставление таблицы:

- `matched`: найден один фрагмент по разделу, набору кодов и наименованию;
- `ambiguous`: несколько физических строк, сохраняемых раздельно;
- `unmatched`: фрагмент не сопоставлен.

Все такие фрагменты имеют `legalVerification=not_verified`. Ни один из этих статусов не равен RULE_REVIEWED или READY_FOR_CALCULATION. `matched` не гарантирует полноту требования: возможны сноски и отдельные продолжения. Читай источник и период действия. Если внешний просмотр превращает таблицу в сплошной текст, это не устраняет неопределённость границ ячеек. Для назначения условия конкретному изделию проверь структуру оригинала, объединённые строки и продолжения; упоминание условия в том же разделе недостаточно. Не объявляй пустой `indexedPosition.text` отсутствием требований. Не копируй предыдущую/следующую строку только по близости или по `contextPositionId`.

Подготовленное правило с `calculationAvailable=true` показывает техническую возможность расчёта. Для юридически значимого результата независимо проверь актуальную норму, сноски, вступление изменений в силу и применимость.

## Безопасные входы

Публичный сервер `navigator719_engine` расположен на существующем Render MCP. Его подключение не предоставляет подтверждённого клиентского контроля доступа. В него нельзя отправлять реальные закрытые данные даже без названия клиента: точные стоимости, состав изделия, маршрут или сведения о партии могут оставаться конфиденциальными после удаления названия.

Для публичного MCP допустимы общедоступные нормативные запросы и полностью синтетические тестовые факты. Наличие закрытого Site не делает публичный Render защищённым. Не переключай соединения и не расширяй права самостоятельно. Если факты нельзя передать, подготовь вход в разрешённом контуре и сообщи, что удалённый расчёт не выполнялся.

Поля `name`, `characteristics`, `reference`, свободный текст и расчётные стоимости также относятся к этой границе. Не отправляй файлы документов через расчётные поля.

## Результат и ошибки

Сохраняй версию, дату, цель, выбранное правило и исходный ответ движка. Укажи отдельно: нормативный статус; что выполнено; что подтверждено документом; что не известно. Технический балл не превращай в заключение о российском происхождении.

Если инструмент недоступен, не выдумывай вызов или результат. Используй исторический кэш только для предварительного поиска с указанием версии. При несовпадении нормативной проверки и движка зафиксируй дефект и не используй ответ как юридически подтверждённый.

LNG требует выбора вариантов, который текущий вход MCP не передаёт; BOM-перечень не поддержан контрактом, доступны только итоговые стоимости. Не скрывай эти ограничения, не заменяй их самодельным калькулятором. Подготовь недостающие входы для последующего исправления существующего контракта.
